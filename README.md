# Inflacion-y-Tipo-de-Cambio-Arg
Este proyecto tiene como objetivo estudiar la dinámica macroeconómica argentina reciente, relacionando la evolución de la tasa de inflación mensual oficial con el comportamiento del tipo de cambio oficial (cierre de mes). Implementa un flujo completo de ETL , almacenamiento local relacional y representación visual de doble escala.
